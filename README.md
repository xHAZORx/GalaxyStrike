# GalaxyStrike

A space shooter developed in Unity 6 using C#.

## Overview

GalaxyStrike is a space combat game built during the Complete C# Unity 3D Game Development in Unity 6 course. The project focuses on gameplay programming, enemy wave systems, UI management, timeline integration, and combat mechanics.

## Features

- Player Spacecraft Controls
- Enemy Wave System
- Projectile Combat
- Health System
- Score Tracking
- Timeline Integration
- UI Management
- Particle Effects
- Scene Transitions
- Game Over Logic

## Technologies Used

- Unity 6
- C#
- Timeline
- Particle Systems
- TextMeshPro
- Scene Management
- Unity Input System
